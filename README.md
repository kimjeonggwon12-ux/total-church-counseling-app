# 총글사 1:1 면담 기록 관리 시스템

도마지파 전주교회 교육부의 1:1 면담 기록 관리 웹앱입니다.

## 📋 기능

- ✅ 84명 사명자 면담 기록 관리
- 📊 사명 진행율 자동 계산
- 📝 면담 내용 입력/수정/초기화
- 📥 보고서 다운로드 (PDF 인쇄)
- 🔍 실시간 검색 기능
- 💾 Google Sheets 자동 저장

## 🛠 기술 스택

- **Backend:** Google Apps Script
- **Frontend:** HTML/CSS/JavaScript
- **Database:** Google Sheets
- **Deployment:** Google Apps Script Web App
